ScoutFlow 도메인/외부접속 설정 안내
====================================

이 버전은 Flask 서버가 127.0.0.1이 아니라 0.0.0.0:8058로 실행되도록 수정되어 있습니다.
따라서 방화벽/공유기/DNS가 맞으면 다른 PC나 외부 네트워크에서도 접속할 수 있습니다.

1) 먼저 같은 와이파이에서 테스트
---------------------------------
00_START_SERVER.bat 실행 후 검은 창에 표시되는 주소 중
"같은 공유기/와이파이 접속: http://내부IP:8058" 주소로 다른 기기에서 접속합니다.

접속이 안 되면 01_ALLOW_FIREWALL_8058_ADMIN.bat 파일을 우클릭하여 관리자 권한으로 실행하세요.

2) 외부 인터넷 접속을 위한 공유기 포트포워딩
-------------------------------------------
공유기 관리자 페이지에서 아래처럼 설정합니다.

외부 포트: 8058
내부 IP: ScoutFlow 실행 PC의 내부 IP
내부 포트: 8058
프로토콜: TCP

포트포워딩 후 외부망에서 아래 주소로 먼저 테스트합니다.
http://공인IP:8058

3) 내도메인.한국 설정
--------------------
웹포워딩이 아니라 IP연결(A)을 사용하세요.

웹포워딩(Redirect): 체크 해제 권장
IP연결(A): 체크
앞칸: 비워두기
뒤칸: 공인 IP 입력

주의: 127.0.0.1을 넣으면 안 됩니다.
127.0.0.1은 접속하는 사람 자기 기기를 뜻하므로 외부 접속이 되지 않습니다.

설정 후 접속 주소:
http://scoutflow.kro.kr:8058

4) 보안 주의
------------
인터넷에 공개하기 전 관리자 비밀번호를 반드시 변경하세요.
기본 비밀번호를 그대로 쓰면 위험합니다.
관리자 기능은 로그인 토큰 검사를 통과해야 실행되도록 되어 있지만,
공개 서버에서는 비밀번호를 강하게 바꾸는 것이 필수입니다.

5) 포트번호 없이 접속하려면
-------------------------
http://scoutflow.kro.kr 처럼 포트 없이 접속하려면 80/443 프록시가 필요합니다.
Windows PC에서 바로 쓰는 경우에는 우선 http://scoutflow.kro.kr:8058 형태가 가장 단순합니다.
