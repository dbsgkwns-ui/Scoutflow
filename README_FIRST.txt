ScoutFlow V59-K12 Public Domain Ready
=====================================

목적:
- 기존 V59-K12 관리자/사용자 모드 구조 유지
- 최근 업데이트 시간을 분 단위까지 표시
- 관리자모드/사용자모드 전환 유지
- 외부 접속을 위해 서버를 0.0.0.0:8058로 실행

실행:
1. 기존 ScoutFlow 검은 창을 모두 닫습니다.
2. 00_START_SERVER.bat을 실행합니다.
3. 로컬 접속: http://127.0.0.1:8058
4. 같은 와이파이 접속 주소는 실행창에 표시됩니다.
5. 도메인 연결은 DOMAIN_SETUP_GUIDE.txt를 확인하세요.

외부 접속 필수 작업:
- Windows 방화벽 TCP 8058 허용
- 공유기 포트포워딩 TCP 8058
- 내도메인.한국에서 IP연결(A)에 공인 IP 입력

보안:
- 인터넷 공개 전 관리자 비밀번호를 반드시 변경하세요.
